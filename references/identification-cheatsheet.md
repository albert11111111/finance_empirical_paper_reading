# 识别设计速查

用于给论文的 empirical design **定名**，不展开教科书。拿不准就写作者自己的叫法，并加「需核对」。

| 设计 | 何时像它 | 笔记里至少写清 |
|------|----------|----------------|
| 横截面回归 | 一期截面；条件相关 | Y、关键 X、控制；是否声称因果 |
| 面板 + FE | 多期；个体/时间 FE | FE 维度、聚类、核心 X 是否时变 |
| 双向固定效应 DiD | 处理组×处理后；TWFE / event-study | 处理定义、时点、平行趋势是否检验 |
| 交错采纳 DiD | 处理时点不同 | 是否讨论异质时点/稳健估计量（若原文有） |
| 事件研究 | 事件窗内异常收益/反应 | 事件、窗长、估计窗、是否累计 |
| IV / 2SLS | 工具变量、内生回归元 | 工具、内生变量、排他限制（作者说法） |
| 断点回归 RD | 强制变量阈值附近 | 强制变量、阈值、带宽、模糊/精确 |
| 匹配 / 加权 | PSM、熵平衡等 | 匹配变量、是否仍做回归调整 |
| 合成控制 | 少数处理单位 | 处理单位、供体池、拟合期 |
| Diff-in-Diff 变体 + 三重差分 | DDD、强度处理 | 各层差分定义 |
| 结构/校准模型 | 估计结构参数或模拟 | 模型名、估的是哪类参数（点到为止） |
| 预测 / 排序组合 | 多空组合、OOS | 信号、持有期、是否交易成本 |

## 定名原则

1. 以**主结果规格**为准，不以附录稳健性为准。
2. 作者写 “quasi-natural experiment” 时，仍落到具体设计（DiD/IV/RD…）。
3. 多设计并存：写「主设计 = …；辅助 = …」。
4. 金融常见「事件研究 + 横截面」：两段都写，标明哪段是 headline。
