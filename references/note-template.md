# 笔记各节说明

按 [SKILL.md](../SKILL.md) 模板产出。本节供写笔记时按需查阅：每节写什么、忌写什么。

## 一句话

**写**：研究问题 + 核心结论，1–2 句，可脱离全文阅读。

**忌**：背景铺垫、文献综述口吻、只写问题不写结论。

## 研究问题与贡献

**写**：
- 论文要回答的因果/描述问题（尽量用可检验的表述）
- 贡献：先标「作者自称」，再可选一句「你的理解」；两者冲突时并存，不替作者改写故事

**忌**：长篇 Related Literature 复述；空泛「填补空白」「贡献重大」。

## 数据与样本

**写**：数据源、样本期、观测单位（firm-year / stock-day 等）、关键筛选与最终样本量（原文有则写）。

**忌**：把数据手册抄一遍；编造 N 或筛选规则。

## 识别策略与模型

**写**：
1. 设计定名（见 [identification-cheatsheet.md](identification-cheatsheet.md)）
2. 规格：Y、核心 X/treatment、主要控制、固定效应、标准误聚类层级（关注表格下方/上方小字）
3. 关键识别假设（各 1 句即可）
4. 主要变量构建方法、经济含义
5. 复杂模型：按下方「查证流程」写清数学原理与选用理由

有明确方程则用原文符号简述；无方程则用「比较逻辑」说明谁与谁比。

**忌**：教科书式展开假设检验理论；把稳健性规格误当成主规格；擅自把相关说成因果（除非作者声称并给出设计）。

### 复杂模型查证（必须做）

**何时算复杂**：名称或设定超出标准 OLS / 面板 FE / 常规 DiD·2SLS·RD·事件研究。例如结构模型、SDF/GMM、仿射期限结构、Kalman、双重机器学习、LASSO/神经网络、交错采纳特殊估计量、合成控制权重、期权/跳跃扩散等。自己叫不全方程的，一律当复杂。

**查证顺序**（未查完不要写原理段）：
1. 原文：抽出模型名、关键方程、符号定义、作者给出的选用理由（Introduction / Empirical Strategy / 附录）。
2. 仍不清楚或原文只有一句带过：网上检索「模型全称 + 标准定义 / 原论文」。优先教材、手册、原作者论文，不用博客口吻复述。
3. 对照：本文的符号/简化是否与标准形式一致；不一致处点明。

**笔记里写三块（每块短，不写教科书）**：
- **是什么**：关键方程（原文符号）+ 1 段直觉（估的是什么、输入输出是什么）
- **为什么用**：相对更朴素设定（如 OLS、普通 DiD）解决了本文的哪一个问题（内生、测量、高维、非线性、定价核等）；尽量用作者理由，缺则写「原文未说明；按标准用途推断：…」
- **读结果时要注意的假设**：1–3 条即可（如排他限制、因子完备、正则化调参）

**忌**：凭记忆默写方程；把 Wikipedia 整页贴进笔记；查完仍不确定却写得像已核实。检索无果则写「需核对：模型 X，原文第…节」。

## 核心结论（带证据）

**写**：
- 按照表格顺序，结合文章正文讨论和表格下方小字，按文章顺序讲清楚每个表格的经济含义，具体包括：回归方法、对应变量、方向、量级（系数/百分比/bp 等原文单位）、经济含义等

- 结合原文对于表格的说明以及你的理解，讲清楚每个表格中最核心重要的证据和结论

- 按图顺序，结合文章正文讨论和表格下方小字，按文章顺序讲清楚每个表格的经济含义，具体包括：回归方法、对应变量、方向、量级（系数/百分比/bp 等原文单位）、经济含义等

- 最后用简单易懂一句话说清楚每个图表在说什么结论。


**忌**：只写「显著为正」；堆砌所有列；编造星号与标准误。

## 机制 / 异质性 / 稳健性

**写**：
- 测了什么、结果方向、是支撑还是削弱主结论。无则整节省略或写「原文无明显机制节」。

- 结合原文的说明讨论，讲清楚每个表格的经济含义，具体包括：回归方法、对应变量、方向、量级（系数/百分比/bp 等原文单位）、经济含义等

- 结合原文对于表格的说明以及你的理解，讲清楚每个表格中最核心重要的证据和结论（从哪个系数看出来结论显著的）

- 每个图表在说什么结论？如何支撑主结论稳健的？


**忌**：把失败稳健性说成「全面稳健」。

## 局限与可读性备注

**写**：
- 作者承认的局限（若有）
- 你读不清、PDF 缺页、表号对不上处 → 「需核对 …」

**忌**：默认写成完整审稿报告；人身或期刊品味评价。
