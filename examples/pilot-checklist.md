# 试跑清单（等用户提供论文）

Skill 文件已就绪。真正试跑需用户提供：

1. 目标论文 PDF（或全文文本）1 篇
2. （可选）认可的范文笔记，用于替换 [sample-note.md](sample-note.md)

## 试跑步骤

1. 用户：附论文并说「按 finance-empirical-paper-reading 精读」
2. Agent：按 [SKILL.md](../SKILL.md) 工作流产出笔记
3. 用户反馈：哪节太长/太短、主结果是否要强制表号、机制节是否默认省略
4. Agent：只改模板措辞与 `note-template.md` 禁忌，不大扩 scope

## 通过标准

- 「一句话」可独立读
- 模型/识别节能复述 Y、关键 X、设计名
- 核心结论有表锚点或明确「无法定位」
- 无编造数字
